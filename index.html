Encabezados <h1> a <h6>

Descripción

Los encabezados definen la estructura jerárquica del contenido. <h1> es el más importante (título principal) y <h6> el menos importante.

Atributos comunes

  • id: Identificador único para el elemento
  • class: Clase CSS para aplicar estilos
  • style: Estilos CSS en línea
  • title: Información adicional (se muestra al pasar el mouse)

Ejemplo de código

<h1> Título Principal </h1>
<h2>Subtítulo</h2>
<h3>Sección</h3>
<h4>Subsección</h4>
<h5>Apartado</h5>
<h6>Detalle</h6>

CSS Asociado

h1 { font-size: 2rem; }
h2 { font-size: 1.8rem; }
h3 { font-size: 1.6rem; }
h4 { font-size: 1.4rem; }
h5 { font-size: 1.2rem; }
h6 { font-size: 1rem; }

Estas reglas establecen los tamaños de fuentes decrecientes para cada nivel de encabezado.

Párrafo <p>

Descripción

Define un párrafo de texto. Es la etiqueta más utilizada para contenido textual de un sitio web.

Atributos comunes

  • align: Alineación del texto (left, right, center, justify)
  • id: Identificador único
  • class: Clase CSS para estilos
  • style: Estilos CSS en línea

Ejemplo de código

<p>Este es un párrafo de ejemplo.</p>
<p>Otro párrafo con <strong>texto en negrita</strong> y <em>texto en cursiva</em>.</p>

CSS Asociado

p {
    margin-bottom: 1rem;
    line-height: 1.6;
    text-align: justify;
}

Estas reglas mejoran la legibilidad con espaciado entre párrafos y altura de línea.

Enlace <a>

Descripción

Crea hipervínculos a otras páginas web, archivos, direcciones de correo o ubicaciones dentro de la misma página.

Atributos comunes

  • href: URL del recurso de destino (obligatorio)
  • target: Donde abrir el enlace (_blank, _self, _parent, _top)
  • rel: Relación entre el documento actual y el enlace
  • download: Indica que el enlace es para descargar un archivo
  • title: Información adicional sobre el enlace

Ejemplo de código

<a href="https://etitc.edu.co" target="_blank">Visita nuestro sitio web</a>
<a href="mailto:wacallejasg@itc.edu.co">Enviar Correo</a>
<a href="#seccion">Ir a sección</a>

CSS Asociado

a {
    color: var(--primary-color);
    text-decoration: none;
    transition: color 0.3s;
}

a:hover {
    color: var(--secondary-color);
    text-decoration: underline;
}

Estas reglas estilizan los enlaces con colores y efectos tipo hover.

Imagen <img>

Descripción

Inserta una imagen en el documento. Esta es una etiqueta autocerrada que no requiere etiqueta de cierre.

Atributos comunes

  • src: Ruta de la imagen (obligatorio)
  • alt: Texto alternativo para accesibilidad (obligatorio)
  • width: Ancho de la imagen en píxeles
  • height: Alto de la imagen en píxeles
  • title: Título que aparece al pasar el mouse
  • loading: Comportamiento de carga (lazy, eager)

Ejemplo de código

<img src="https://shorturl.at/8UB0s" alt="Descripción de la imagen" width="400" height="300" title="Título de la imagen">

CSS Asociado

img {
    max-width: 100%;
    height: auto;
    border-radius: 8px;
    box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

Estas reglas hacen las imágenes responsivas y les añaden estilos visuales.

Resultado Visual

División <div>

Descripción

Contenedor genérico que agrupa elementos para propósitos de estilos o para crear secciones en un documento. No tiene significado semántico.

Atributos comunes

  • id: Identificador único
  • class: Clase CSS para estilos
  • style: Estilos CSS en línea

Ejemplo de código

<div class="contenedor">
    <h2>Título de Sección</h2>
    <p>Contenido dentro del div</p>
</div>

CSS Asociado

.contenedor {
    background-color: #f0f8ff;
    padding: 20px;
    border: 1px solid #d1e7ff;
    border-radius: 8px;
    margin-bottom: 20px;
}

Estas reglas aplican estilos visuales a los contenedores div.

Span <span>

Descripción

Contenedor en línea genérico para texto o elementos en línea. Se usa para aplicar estilos a una parte de un texto sin cambiar su significado real.

Atributos comunes

  • id: Identificador único
  • class: Clase CSS para estilos
  • style: Estilos CSS en línea

Ejemplo de código

<p>Este es un texto con una parte <span class="destacado">resaltada</span>.</p>

CSS Asociado

.destacado {
    background-color: #ffc107;
    color: white;
    padding: 2px 6px;
    border-radius: 4px;
}

Estas reglas destacan o resaltan visualmente el texto dentro del span.

Resultado Visual

Este es un texto con una parte resaltada.

Lista no ordenada <ul>

Descripción

Crea una lista de elementos sin un orden específico. Cada elemento de la lista se define con <li>.

Atributos comunes

  • id: Identificador único
  • class: Clase CSS para estilos
  • style: Estilos CSS en línea

Ejemplo de código

<ul>
    <li>Elemento 1</li>
    <li>Elemento 2</li>
    <li>Elemento 3</li>
</ul>

CSS Asociado

ul {
    list-style-type: disc;
    padding-left: 1.5rem;
    margin-bottom: 1rem;
}

ul li {
    margin-bottom: 0.5rem;
}

Estas reglas estilizan las listas con viñetas y espaciado.

Resultado Visual

  • Elemento 1
  • Elemento 2
  • Elemento 3

Lista ordenada <ol>

Descripción

Crea una lista numerada de elementos donde el orden es importante. Cada elemento de la lista se define con <li>.

Atributos comunes

  • type: Tipo de numeración (1, A, a, I, i)
  • start: Número inicial de la lista
  • reversed: Invierte el orden de la numeración
  • id: Identificador único

Ejemplo de código

<ol type="1" start="1">
    <li>Primer paso</li>
    <li>Segundo paso</li>
    <li>Tercer paso</li>
</ol>

CSS Asociado

ol {
    list-style-type: decimal;
    padding-left: 1.5rem;
    margin-bottom: 1rem;
}

ol li {
    margin-bottom: 0.5rem;
}

Estas reglas estilizan la lista numerada con espaciado adecuado.

Resultado Visual

  1. Primer paso
  2. Segundo paso
  3. Tercer paso

Tabla <table>

Descripción

Define una tabla que organiza datos en filas y columnas. Se usa con <tr> (filas), <th> (celda de encabezado) y <td> (celda de datos).

Atributos comunes

  • border: Ancho del borde de la tabla
  • cellpadding: Espacio dentro de las celdas
  • cellspacing: Espacio entre celdas
  • width: Ancho de la tabla

Ejemplo de código

<table border="1">
    <thead>
        <tr>
            <th>Nombre</th>
            <th>Edad</th>
            <th>Ciudad</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ana</td>
            <td>25</td>
            <td>Bogotá</td>
        </tr>
        <tr>
            <td>Luis</td>
            <td>30</td>
            <td>Medellín</td>
        </tr>
    </tbody>
</table>

CSS Asociado

table {
    width: 100%;
    border-collapse: collapse;
    margin-bottom: 1rem;
}

th, td {
    border: 1px solid #ddd;
    padding: 8px 12px;
    text-align: left;
}

th {
    background-color: #667eea;
    color: white;
}

tr:nth-child(even) {
    background-color: #f9f9f9;
}

tr:hover {
    background-color: #f1f3f5;
}

Estas reglas estilizan la tabla con bordes, colores y efectos hover.
